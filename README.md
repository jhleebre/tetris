# 별조각 쌓기

우주에서 떨어지는 별조각 블록을 맞춰 가로줄을 채우고 지우는 웹 퍼즐 게임입니다. 브라우저만 있으면 설치 없이 플레이할 수 있습니다.

**▶ [플레이하기](https://jhleebre.github.io/tetris/)**

## 게임 규칙

- 일곱 가지 모양의 블록이 위에서 떨어집니다. 가로줄 하나를 빈칸 없이 채우면 그 줄이 사라집니다.
- 한 번에 여러 줄을 지울수록 점수가 커지고, 네 줄을 연달아 지우면 1.5배, 줄을 계속 이어서 지우면 콤보 점수가 더해집니다. 판을 완전히 비우면 큰 보너스가 있습니다.
- 바닥에 닿은 블록은 0.5초 뒤에 고정됩니다. 그 사이에 움직이거나 돌리면 시간이 다시 채워집니다(최대 15번).
- 블록이 꼭대기 밖에서 고정되거나 새 블록이 나올 자리가 없으면 끝납니다.
- 반투명 윤곽은 블록이 떨어질 자리를 보여 줍니다. 판 위쪽 네 줄까지 쌓이면 테두리가 빨갛게 깜빡입니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `←` `→` 또는 `A` `D` | 좌우로 움직이기 (누르고 있으면 계속 이동) |
| `↓` 또는 `S` | 천천히 내리기 (한 칸에 1점) |
| `↑` `X` 또는 `W` | 시계 방향 회전 |
| `Z` 또는 `Ctrl` | 반시계 방향 회전 |
| `스페이스` | 바로 내리기 (한 칸에 2점) |
| `C` 또는 `Shift` | 보관 (블록 하나에 한 번) |
| `R` | 다시 시작 |
| `Esc` 또는 `P` | 일시정지 · 메뉴 |
| `N` | 배경음악 켜기/끄기 |
| `M` | 모든 소리 켜기/끄기 |

터치 기기에서는 화면 아래 버튼으로 조작합니다.

## 모드

| 모드 | 목표 | 기록 |
| --- | --- | --- |
| 마라톤 | 10줄마다 레벨이 올라 빨라짐, 150줄 달성 | 최고 점수 |
| 40줄 | 40줄을 최대한 빨리 지우기 | 최단 시간 |
| 2분 | 2분 동안 최대한 많은 점수 | 최고 점수 |
| 청소 | 구멍 난 회색 쓰레기 줄 10개를 모두 지우기 | 최단 시간 |

## 로컬 실행

빌드 과정은 없지만, 코드가 ES 모듈로 나뉘어 있어서 `index.html`을 파일로 바로 열면 동작하지 않습니다. 프로젝트 폴더에서 로컬 서버를 띄운 뒤 브라우저로 접속하세요.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000` 을 엽니다. GitHub Pages 같은 정적 호스팅에는 그대로 올리면 됩니다. Google Fonts만 CDN에서 불러옵니다(없으면 시스템 글꼴로 표시).

## 폴더 구조

```
index.html              화면 마크업과 모듈 진입점
css/style.css           HUD · 메뉴 · 터치 버튼 스타일
src/
  main.js               초기화와 프레임 루프
  game.js               게임 흐름 (메뉴/플레이/일시정지/종료/결과), 입력 → 동작, 키 반복
  config.js             판 크기, 타이밍, 점수 상수
  data/modes.js         모드 목록 (목표, 제한 시간, 쓰레기 줄, 색)
  core/                 ← DOM을 쓰지 않는 순수 로직 (Node에서도 실행)
    pieces.js           블록 모양, 회전 상태, 벽 차기
    board.js            판, 충돌 판정, 줄 지우기
    bag.js              시드 기반 난수, 7개 묶음 순서
    engine.js           시뮬레이션 (이벤트 콜백으로 결과 전달)
    bot.js              자리 평가 봇 (메뉴 배경 데모, 자동 플레이, 테스트)
  render/
    view.js             캔버스 레이아웃과 그리기 (판, 그림자, 보관/다음)
    palette.js          블록 색과 캐시된 블록 이미지
    effects.js          줄 지우기 섬광·파편, 낙하 자국, 화면 흔들림, 떠오르는 글자
  audio/sound.js        WebAudio로 합성하는 효과음
  audio/music.js        WebAudio로 합성·예약 재생하는 배경음악 (레벨이 오르면 빨라짐)
  ui/hud.js             HUD, 배너, 메뉴, 결과 카드
  ui/input.js           키보드·터치 → 동작 이름
  util/storage.js       기록 저장 (localStorage)
tools/
  core-check.js         로직 확인 (회전, 줄 지우기, 점수, 보관, 봇이 모든 모드를 깰 수 있는지)
  check-core.html       브라우저에서 확인 (로컬 서버로 열기)
  check-core.mjs        Node에서 확인 (`npm test`)
```

이미지·소리 파일은 없습니다. 블록과 배경은 캔버스로 그리고, 효과음과 배경음악은 `audio/`에서 합성합니다.

## 확인하기

로직을 고친 뒤에는 로컬 서버에서 `http://localhost:8000/tools/check-core.html` 을 열거나, Node가 있다면 아래 명령을 실행합니다.

```bash
npm test
```

## 자동 플레이 (QA)

주소 뒤에 `?autoplay`를 붙이면 봇이 실제 게임을 플레이합니다. 자동 플레이 기록은 최고 기록에 저장되지 않으며, `Esc`로 멈추고 메뉴로 돌아갑니다.

- `http://localhost:8000/?autoplay` : 마라톤
- `http://localhost:8000/?autoplay&mode=sprint` : 40줄 (`marathon` `sprint` `ultra` `dig`)
